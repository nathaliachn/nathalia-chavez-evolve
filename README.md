# Nathalia Chavez: Evolve

Create a premium, immersive personal portfolio for Nathalia Chavez Nieme, positioned as a Tech Founder · Builder · Creator.

The website should feel disruptive, sophisticated, futuristic and highly visual — not like a traditional developer portfolio or CV.

Visual direction:

 iridescent gradients: electric blue, cyan, violet, subtle pink

 black + off-white base

 selective glassmorphism

 clean editorial typography

 subtle 3D depth

 cinematic motion

 premium tech aesthetic

The experience must be intuitive, responsive and visually memorable.

Build these sections:

 Hero with Nathalia’s portrait, strong positioning and subtle interactive 3D/light effects.

 “What I bring” showing Technology, Product, AI, Strategy, Business, Design and Execution as a connected visual system.

 Selected experience: Personal Pay, Farmacity, British Airways, Banco de Chile, M720 and Globant.

 Story section connecting her background as a high-performance athlete with technology, product and entrepreneurship.

 Community / media: Women in Tech, Laboratoria talk, podcast and Women Techmakers.

 Thinking / ideas.

 Partnership CTA for founders, investors, partners and clients.

Use React + TypeScript + Tailwind + Framer Motion.

Important:

 Do not call her “Software Engineer” as her main identity.

 Do not invent achievements or metrics.

 Do not overuse 3D or animations.

 Prioritize strong art direction, hierarchy and interaction.

 English first, but structure it to support Spanish later.

Start by generating the first visual homepage version. Do not overengineer the architecture yet.
